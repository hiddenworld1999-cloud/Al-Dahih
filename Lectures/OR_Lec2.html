المحاضرة الثانية - صياغة مسائل البرمجة الخطية (Problem Formulation)

📝 المسألة الأولى (منتجات الشركة):

تنتج شركة إنتاجية ثلاثة منتجات. وكل منتج يحتاج إلى ثلاثة أنواع من المدخلات هي: المادة الخام، الطاقة البشرية، والطاقة الميكانيكية. ويوضح الجدول التالي احتياجات وحدة المنتج من مدخلات الإنتاج والإنتاجية لكل مدخل والربح المتوقع لكل منها:

البيان احتياجات المنتج من مدخلات الإنتاج كمية المدخلات المتاحة
منتج 1 منتج 2 منتج 3
المادة الخام (كجم) 2 3 4 1200
طاقة بشرية (ساعة) 1 2 3 900
طاقة ميكانيكية (ساعة) 3 1 6 1500
الربح (د.ل. للوحدة) 10 7 5 -

المطلوب: صياغة نموذج البرمجة الخطية لتحديد الكمية الواجب إنتاجها من كل منتج لتعظيم الربح إلى أقصى حد ممكن.

الحل بالتفصيل (خطوة بخطوة):

1. تحديد متغيرات النموذج (Decision Variables):

بما أن المطلوب هو كمية الإنتاج من كل منتج، فإن المتغيرات هي:

  • x1 = كمية الإنتاج من المنتج 1
  • x2 = كمية الإنتاج من المنتج 2
  • x3 = كمية الإنتاج من المنتج 3

2. صياغة دالة الهدف (Objective Function):

الهدف هو تعظيم الربح الإجمالي. الربح بيجي من (ربح الوحدة × كمية الإنتاج).

Maximize Z = 10x1 + 7x2 + 5x3

3. صياغة القيود (Constraints):

القيود هي حدود الموارد المتاحة (المادة الخام، الطاقة البشرية، الطاقة الميكانيكية).

// قيد المادة الخام
2x1 + 3x2 + 4x3 ≤ 1200

// قيد الطاقة البشرية
x1 + 2x2 + 3x3 ≤ 900

// قيد الطاقة الميكانيكية
3x1 + x2 + 6x3 ≤ 1500

4. شروط عدم السلبية (Non-Negativity):

كمية الإنتاج لازم تكون موجبة أو صفر (مينفعش ننتج كمية سالبة).

x1, x2, x3 ≥ 0

📝 المسألة الثانية (شركة الاستثمارات):

قررت إحدى شركات الاستثمارات الداخلية استثمار مبلغ 50,000 د.ل في ثلاثة مشاريع هي: بناء عقارات، إدارة مشروع زراعي، وتجارة سلع. وقد قدّر عائد أرباحها السنوي بنسبة 7%، 9%، 14% على التوالي. ومن ضمن خططات الشركة الاستثمارية:

  1. الحصول على العائد السنوي بها لا يقل عن 5000 د.ل.
  2. توفير 10,000 على الأقل (في المشروع الزراعي).
  3. التوفير من تجارة السلع الداخلية لا يزيد عن التوفير في باقي الاستثمارات.
  4. التوفير في بناء العقارات لا يقل عن 5000 د.ل ولا يزيد عن 15,000 د.ل.

المطلوب: كيفية توزيع المبلغ المستثمر 50,000 د.ل في المشاريع الثلاثة بحيث يحقق أكبر استثمار ممكن.

الحل بالتفصيل (خطوة بخطوة):

1. تحديد متغيرات النموذج:

  • x1 = الاستثمار في العقارات (د.ل)
  • x2 = الاستثمار في إدارة المشروع الزراعي (د.ل)
  • x3 = الاستثمار في تجارة السلع (د.ل)

2. صياغة دالة الهدف:

الهدف هو تعظيم العائد السنوي (الربح). بنضرب نسبة العائد في المبلغ المستثمر في كل مشروع.

Maximize Z = 0.07x1 + 0.09x2 + 0.14x3

3. صياغة القيود:

// 1. العائد السنوي لا يقل عن 5000
0.07x1 + 0.09x2 + 0.14x3 ≥ 5000

// 2. توفير 10,000 على الأقل (للمشروع الزراعي)
x2 ≥ 10,000

// 3. التوفير في تجارة السلع لا يزيد عن باقي الاستثمارات (العقارات + الزراعي)
x3 ≤ x1 + x2 // أو: -x1 - x2 + x3 ≤ 0

// 4. التوفير في العقارات بين 5000 و 15000
x1 ≥ 5000
x1 ≤ 15000

// 5. مجموع الاستثمارات لا يزيد عن 50,000
x1 + x2 + x3 ≤ 50,000

4. شروط عدم السلبية:

x1, x2, x3 ≥ 0
