🧠 مفاهيم البرمجة وحل المشكلات

البرمجة: أخذ مدخلات (Input)، وإجراء عمليات عليها داخل "الصندوق الأسود" (الكود)، لإنتاج مخرجات (Output).

حل المشكلات: الطريقة المنهجية لتحديد المشكلة وإنشاء حلول. تبدأ بفهم المتطلبات وتنتهي بإنشاء برنامج.

مراحل حل المشكلات:

  1. فهم المشكلة (Problem Understanding): تحديد طبيعتها وجمع المعلومات (مثال: برنامج لحساب رصيد البنك).
  2. تخطيط الحل (Planning): تصميم خطة أو خوارزمية (Pseudocode أو Flowchart). (مثال: تقسيم المشكلة لإدخال، معالجة، وإظهار النتيجة).
  3. تنفيذ الحل (Implementing): كتابة الكود (Python/Java). (مثال: حساب صافي السعر بعد الخصم).
  4. فحص النتيجة (Testing & Debugging): اختبار البرنامج وتصحيح الأخطاء (مثال: التحقق من الحساب لعدة حالات).

⚙️ الخوارزميات (Algorithms)

التعريف: تسلسل من التعليمات يصف طريقة حل مشكلة. يجب أن تُكتب بلغة بسيطة، دقيقة، غير غامضة، لا تتكرر بلا نهاية، وتنتهي بعدد محدود من الخطوات لإعطاء النتائج.

💡 مثال دليل الهاتف (Big-O Notation):

للبحث عن اسم، قد نقرأ صفحة وراء صفحة (بطيء)، أو نذهب لمنتصف الدليل ونسأل "هل الاسم يمين أم يسار؟" ونقسم المشكلة لنصفين (الأسرع). سرعة الخوارزميات تُعرف بـ Big-O.

صفات الخوارزمية الجيدة:

  • الوقت (Time): وقت تنفيذ أقل = خوارزمية أفضل.
  • الذاكرة (Memory): استهلاك ذاكرة أقل = خوارزمية أفضل.
  • الدقة (Accuracy): إعطاء نتائج صحيحة.

مكونات الخوارزمية:

  • العبارات (Statements): إدخال/إخراج، تخصيص (c=a+b)، تعليقات.
  • الحالات (States): المتغيرات وحالة البرنامج.
  • تدفق التحكم (Control Flow): تسلسلي، شرطي، تكرار.
  • الدوال (Functions): كتلة كود تُستخدم لأداء إجراء مترابط.

📝 الخوارزمية الزائفة (Pseudocode)

نسخة قابلة للقراءة من الكود، تُكتب بلغة إنجليزية بسيطة للتركيز على المنطق وتسهيل التواصل وتحويلها لأي لغة برمجة.

القواعد الأساسية:

  • كل أمر في سطر (Only one statement per line).
  • الكلمات المفتاحية بحروف كبيرة: READ, WRITE, IF, ELSE, ENDIF, WHILE, REPEAT, UNTIL.
  • استخدام المسافات البادئة (Indentation) وكتابة نهاية الهياكل (ENDIF).

المميزات والعيوب:

المميزات: سهلة الكتابة والتعديل والقراءة، تطبق المفاهيم المنظمة، وتحويلها للكود أسهل من الـ Flowchart.

العيوب: ليست مرئية (زي الـ Flowchart)، ولا يوجد لها أسلوب أو تنسيق موحد.

أمثلة (Pseudocode):

// 1. Grade Example
READ Grade
IF Grade >= 50 THEN
    PRINT "ناجح"
ELSE
    PRINT "راسب"
ENDIF

// 2. Average Example
1. READ name, department, mark1, mark2, mark3
2. Total = mark1 + mark2 + mark3
3. Average = Total / 3
4. PRINT name, department, mark1, mark2, mark3

🔀 تدفق التحكم (Control Flow) والـ Flowchart

أنواع تدفق التحكم:

  1. تسلسلي (Sequential): تنفيذ من الأعلى للأسفل.
  2. شرطي (Selection): قرار بناءً على شرط. (هيكله: IF CONDITION is TRUE then perform action ELSE IF FALSE then perform action).
  3. تكرار (Looping): تكرار حتى يتحقق الشرط.

أشكال الـ Flowchart الأساسية:

  • البيضاوي (Oval): للبداية (Start) والنهاية (Stop).
  • متوازي الأضلاع (Parallelogram): للإدخال والإخراج (Input / Print).
  • المعين (Diamond): لاتخاذ القرار أو الشرط (Decision).
  • المستطيل (Rectangle): للعمليات الحسابية أو التخصيص (Process).

🧩 الدوال (Functions)

كتلة كود منظمة وقابلة لإعادة الاستخدام (Sub-routines/Methods). عناصرها: الاسم (Name)، الجسم (Body)، المعاملات (Formal Parameter)، نوع النتيجة (Optional Result Type).

// Main function
Step 1: Start
Step 2: Call the function add()
Step 3: Stop

Step 2: Get a, b Values
Step 3: add c = a + b
Step 4: Print c
Step 5: Return

📦 المتغيرات (Variables) وأنواع البيانات

المتغير: مكان في الذاكرة لتخزين قيم من نوع بيانات محدد، وله اسم ونوع.

قواعد التسمية:

  • يبدأ بحرف (a-z, A-Z) أو شرطة سفلية (_). (صحيح: x, _value | خطأ: 1var, #name).
  • يحتوي على أحرف وأرقام وشرطة سفلية. (صحيح: user1 | خطأ: user-name, my var).
  • حساس لحالة الأحرف (Case-Sensitive): myVar ≠ myvar.
  • لا يمكن استخدام كلمات محجوزة: if, for, while, def.
  • يفضل أن يكون وصفياً (Descriptive) مثل student_name، واستخدام Snake Case.

تتبع المتغيرات في الذاكرة:

int calls = 4; (تخزين 4) -> calls = 5; (تحديث لـ 5) -> calls = calls + 1; (القيمة القديمة 4 + 1 = 5).

🧮 العمليات الحسابية وأولوياتها

  • + جمع (3+5=8)، - طرح (10-4=6)، * ضرب (2*6=12)، / قسمة (15/3=5.0).
  • // قسمة صحيحة (17//5 = 3)، % باقي القسمة (17%5 = 2)، ** الأس (2**3 = 8).

أمثلة أولويات تنفيذ العمليات (من المحاضرة):

1. بدون أقواس: 2 + 3 * 4 -> الضرب أولاً (12) ثم الجمع -> 14.

2. مع الأس: 2 * 3 ** 2 + 1 -> الأس أولاً (9)، ثم الضرب (18)، ثم الجمع -> 19.

3. متساوية الأولوية: 10 / 2 * 3 -> من اليسار لليمين -> قسمة (5.0) ثم ضرب -> 15.0.

4. استخدام الأقواس: (2 + 3) * 4 -> الأقواس أولاً (5) ثم الضرب -> 20.

5. تعقيد: 4 + 2 / 6 - 3 * 1 -> القسمة (0.33) والضرب (3.0) أولاً، ثم الجمع والطرح من اليسار لليمين -> النتيجة النهائية.

⚖️ العمليات المنطقية والفرق بين (=) و (==)

⚠️ نقطة الامتحان الأهم!

  • علامة (=): Assignment operator، لتخزين قيمة. (مثال: a = 4).
  • علامة (==): Logical operator، للمقارنة (True/False). (مثال: a == b).

خطأ شائع: IF (a=b) يسبب Error، الصحيح IF (a==b).

علامات المقارنة ومقارنة النصوص:

يمكن مقارنة النصوص أبجدياً: "apple" == "apple" (True)، "cat" < "dog" (True).

🐍 التطبيق العملي في بايثون (أمثلة السلايدات)

1. طباعة النصوص (Strings):

# يمكن استخدام علامات تنصيص مفردة أو مزدوجة
print("It's alright")
print("He is called 'Johnny'")
print('He is called "Johnny"')

الشرح: دالة print() بتطبع أي نص بين الأقواس. لو عايز تطبع علامة تنصيص جوه النص، استخدم نوع مختلف عن النوع اللي فاتح بيه الكود.

2. إدخال البيانات وحساب المجموع:

num1 = float(input("العدد الأول: "))
num2 = float(input("العدد الثاني: "))
sum = num1 + num2
print("المجموع هو", sum)

الشرح: input() بتستقبل نص من المستخدم. بنلفها بـ float() عشان نحول النص لرقم عشري ونقدر نجمع.

3. طباعة القيم المنطقية (Boolean):

a = 5
b = 7
print(a > b) # Output: False
print(a < b) # Output: True

الشرح: أي شرط بنكتبه نتيجته لازم تكون إما True أو False. هنا طبعنا حاصل المقارنة مباشرة.

🔀 4. الأمر الشرطي (IF-ELSE)

a = 5
b = 7
if a > b:
    print("a is greater")
else:
    print("b is greater")

الشرح: في بايثون بنكتب if و else بحروف صغيرة، وبنحط نقطتين (:) في آخر السطر. الكود اللي جوه الشرط لازم يكون متزحزح لليمين بمسافة (Indentation).

🔁 5. حلقة التكرار (FOR Loop)

# طباعة الأرقام من 1 إلى 10
for i in range(1, 11):
    print("The number is", i)

الشرح: range(1, 11) معناها ابدأ من 1 واقف قبل الـ 11 (يعني هيطبع لحد 10). لاحظ النقطتين : والمسافة البادئة قبل print.

📊 شرح الخطوات (Flowchart) للـ Loop

  • التهيئة (Initialization): i = 0
  • الشرط (Condition): i <= 10 (لو صح ننفذ، لو غلط نخرج من اللوب).
  • تنفيذ الكود (Code Inside Loop).
  • تحديث العداد (Update): i = i + 1
