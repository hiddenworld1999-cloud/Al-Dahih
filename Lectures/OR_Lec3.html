المحاضرة الثالثة - الحل البياني لمسائل البرمجة الخطية (متغيرين فقط)

📝 المثال الأول (الحل البياني الأساسي)

السؤال:

استخدم الطريقة البيانية لحل مسألة البرمجة الخطية التالية:

Maximize Z = x1 + 2x2
Subject to (St.):
2x1 + x2 ≤ 400
x1 ≤ 100
2x1 + 2x2 ≥ 100
x1, x2 ≥ 0

الحل بالتفصيل (خطوة بخطوة):

1. إيجاد نقاط التقاطع لكل قيد:

  • القيد الأول (2x1 + x2 = 400):
    بوضع x1 = 0 → x2 = 400 (النقطة 0, 400).
    بوضع x2 = 0 → 2x1 = 400 → x1 = 200 (النقطة 200, 0).
  • القيد الثاني (x1 = 100):
    هو خط رأسي يمر بـ x1 = 100.
  • القيد الثالث (2x1 + 2x2 = 100):
    بوضع x1 = 0 → 2x2 = 100 → x2 = 50 (النقطة 0, 50).
    بوضع x2 = 0 → 2x1 = 100 → x1 = 50 (النقطة 50, 0).

2. إيجاد نقط التقاطع بين القيود (زوايا منطقة الحلول الممكنة):

من الرسم البياني (الموضح في الصفحة التالية)، تتقاطع القيود لتكوين منطقة الحلول الممكنة (المنطقة المظللة). نقوم بحساب قيمة دالة الهدف (Z) عند كل نقطة زاوية:

النقطة (Point) الإحداثيات (x1, x2) التعويض في دالة الهدف Z = x1 + 2x2 قيمة Z
A (50, 0) (1 × 50) + (2 × 0) 50
B (100, 0) (1 × 100) + (2 × 0) 100
C (100, 200) (1 × 100) + (2 × 200) 500
D (0, 400) (1 × 0) + (2 × 400) 800 (الحل الأمثل)
E (0, 50) (1 × 0) + (2 × 50) 100

الاستنتاج النهائي:

بما أن الهدف هو التعظيم (Maximize)، نختار النقطة التي تعطي أكبر قيمة لـ Z. النقطة هي D (0, 400)، وقيمة الربح العظمى هي Z = 800.

طريقة حساب النقطة C: تقاطع القيد الأول (2x1 + x2 = 400) مع القيد الثاني (x1 = 100). بالتعويض: 2(100) + x2 = 400 → 200 + x2 = 400 → x2 = 200.

📐 أنواع القيود في الرسم البياني

عند رسم القيود في مسائل البرمجة الخطية، يختلف نوع الخط والاتجاه بناءً على علامة القيد:

  • القيد المحدد (≤): يُرسم بخط متصل، ويتم التظليل نحو نقطة الأصل (0,0).
  • القيد غير المحدد (<): يُرسم بخط متقطع (Dashed)، ويتم التظليل نحو نقطة الأصل.
  • القيد المتساوي (=): يُرسم بخط متصل، ولا يتم التظليل (الحل يقع على الخط نفسه فقط).

X1 + X2 = 10

⚠️ الحالات الخاصة في الطريقة البيانية

1. عدم وجود حلول مقبولة (No Feasible Solution)

تحدث هذه الحالة عندما لا تتقاطع القيود معاً لتكوين منطقة حلول مشتركة (لا توجد منطقة ممكنة).

مثال 1:

Maximize Z = X1 + 3X2
St. X1 + X2 ≥ 100
X1 + X2 ≤ 60
X1, X2 ≥ 0
لا توجد منطقة حلول مشتركة

2. الحل غير المحدود (Unbounded Solution)

تحدث عندما تكون منطقة الحلول الممكنة مفتوحة من أحد الاتجاهات، وتستمر دالة الهدف في الزيادة إلى ما لا نهاية (في حالة التعظيم) دون أن تصطدم بأي قيد.

مثال 2:

Maximize Z = 3X1 + 2X2
St. X1 + X2 ≥ 60
X2 ≥ 10
X1, X2 ≥ 0
المنطقة مفتوحة (غير محدودة)

♾️ 3. حلول مثلى متعددة (Multiple Optimal Solutions)

تحدث عندما يكون خط دالة الهدف موازياً لأحد أضلاع منطقة الحلول الممكنة. في هذه الحالة، كل نقطة على هذا الضلع تعتبر حلاً مثالياً وتعطي نفس القيمة العظمى (أو الصغرى) لدالة الهدف.

مثال 3:

Maximize Z = X1 + X2
St. X1 + X2 ≤ 80
X1 ≥ 30
X2 ≥ 20
X1, X2 ≥ 0

الحل:

  • القيد 1: X1 + X2 = 80 (0,80) و (80,0)
  • القيد 2: X1 = 30
  • القيد 3: X2 = 20
النقطة الإحداثيات (X1, X2) Z = X1 + X2 النتيجة
A (30, 20) (1×30) + (1×20) 50
B (60, 20) (1×60) + (1×20) 80
C (30, 50) (1×30) + (1×50) 80

الاستنتاج:

بما أن النقطتين B و C تعطيان نفس القيمة العظمى (Z = 80)، فإن أي نقطة تقع على الخط الواصل بين B و C (الخط BC) تعتبر حلاً أمثلاً متساوياً، والربح سيكون دائماً 80.
