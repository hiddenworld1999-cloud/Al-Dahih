تطبيقات في البرمجة - د. مريم سامي

🏗️ يعني إيه برمجة شينية (OOP)؟

الفكرة ببساطة: الـ OOP هو طريقة لتنظيم الكود بتعتمد على "الكائنات" (Objects). تخيل إنك بتبني بالليجو، بدل ما تحط الكود كله في سطر طويل (زي البرمجة التقليدية)، بتجمع الكود في قوالب (Classes) وكل قالب بيطلع منه "كائنات" (Objects).

الفرق بين Procedural و OOP:

  • Procedural (الطريقة القديمة): البيانات في حتة، والدوال في حتة. لو عندك 10 طلاب، هتكتب 10 متغيرات و10 دوال.
  • OOP (الطريقة الحديثة): البيانات والسلوكيات (الدوال) مع بعض في قالب واحد. لو عندك 10 طلاب، بتعمل Class اسمه Student وتطلع منه 10 Objects.

ليه نستخدم OOP؟ (المميزات)

  • الهيكلة (Structure): بتمثل الحاجات الحقيقية كقوالب (Classes).
  • إعادة الاستخدام (Reuse): بنستخدم الوراثة بدل ما نكرر الكود.
  • الأمان (Safety): بنخبي البيانات جوه الدوال عشان محدش يغيرها غلط.
  • سهولة الصيانة: الكود بيبقى منظم ومفيهوش تكرار.
💡 مثال للتوضيح (العربية):
Class (الفئة): هي "التصميم" أو "القالب" بتاع العربية (بيقولك دي عربية ليها لون، وسرعة، وباب).
Object (الكائن): هي العربية الحقيقية اللي ماشية في الشارع (زي عربية "أحمد" اللي لونها أحمر، وعربية "محمد" اللي لونها أزرق). كلهم من نفس القالب بس بياناتهم مختلفة.

📦 الفئة (Class) والكائن (Object) والـ __init__

مثال 1: إنشاء Class و Object واستخدام الـ __init__

class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

p1 = Person("Emil", 36)
print(p1.name)
print(p1.age)
>_ Terminal Output
Emil
36
💡 الشرح سطر بسطر:
• class Person: بنقول لبايثون "اعملي قالب جديد اسمه Person".
• def __init__(self, name, age): دي دالة البداية (Constructor)، بتشتغل أوتوماتيك أول ما تنشئ كائن. الـ self هو الكائن نفسه، والـ name و age دول القيم اللي هتيجي من بره.
• self.name = name بنخزن القيمة اللي جات (name) جوه الكائن نفسه (self.name).
• self.age = age نفس الكلام للسن.
• p1 = Person("Emil", 36) هنا إحنا أنشأنا كائن جديد اسمه p1 من القالب Person، وادينا الاسم "Emil" والسن 36.
• print(p1.name) بنطبع الاسم اللي متخزن جوه p1.

مثال 2: تعيين قيمة افتراضية (Default Value)

class Person:
    def __init__(self, name, age=18):
        self.name = name
        self.age = age

p1 = Person("Emil")
p2 = Person("Tobias", 25)
print(p1.name, p1.age)
print(p2.name, p2.age)
>_ Terminal Output
Emil 18
Tobias 25
💡 الشرح سطر بسطر:
• age=18 دي قيمة افتراضية. يعني لو المستخدم مدخلش سن، بايثون هتعتبره 18.
• p1 = Person("Emil") هنا مدخلناش سن، فهيتحط 18 أوتوماتيك.
• p2 = Person("Tobias", 25) هنا دخلنا 25، فهيتحط 25.
• print(p1.name, p1.age) هتطبع Emil 18.

⚙️ الدوال جوه الكلاس (Methods)

مثال 3: دالة تطبع معلومات العربية

class Car:
    def __init__(self, brand, model, year):
        self.brand = brand
        self.model = model
        self.year = year

    def display_info(self):
        print(f"{self.year} {self.brand} {self.model}")

car1 = Car("Toyota", "Corolla", 2020)
car1.display_info()
_ Terminal Output
2020 Toyota Corolla
💡 الشرح سطر بسطر:
• الـ __init__ هنا بياخد 3 قيم (براند، موديل، سنة) وبيخزنهم جوه الكائن.
• def display_info(self): دي دالة تانية جوه الكلاس، وظيفتها تطبع البيانات.
• f"{self.year} {self.brand} {self.model}" دي طريقة تنسيق النص (f-string) عشان نحط المتغيرات جوه النص.
• car1 = Car(...) بننشئ كائن جديد ونبعتله البيانات.
• car1.display_info() بنستدعي الدالة عشان تطبع.

مثال 4: دالة ترحب بالمستخدم

class Person:
    def __init__(self, name):
        self.name = name

    def greet(self):
        print("Hello, my name is " + self.name)

p1 = Person("Emil")
p1.greet()
_ Terminal Output
Hello, my name is Emil
💡 الشرح سطر بسطر:
• الـ __init__ هنا بياخد الاسم بس ويخزنه في self.name.
• def greet(self): دالة تطبع ترحيب.
• "Hello, my name is " + self.name هنا بنجمع نص ثابت مع الاسم اللي متخزن جوه الكائن.
• p1.greet() بنستدعي الدالة عشان تشتغل.

مثال 5: الدوال بتاخد Parameters (زي الدوال العادية)

class Calculator:
    def add(self, a, b):
        return a + b

    def multiply(self, a, b):
        return a * b

calc = Calculator()
print(calc.add(5, 3))
print(calc.multiply(4, 7))
_ Terminal Output
8
28
💡 الشرح سطر بسطر:
• الكلاس Calculator فيه دالتين: واحدة للجمع وواحدة للضرب.
• def add(self, a, b) بتاخد رقمين، وبترجع الناتج return a + b.
• calc = Calculator() عملنا كائن جديد.
• calc.add(5, 3) استدعينا دالة الجمع واديناها 5 و 3، رجعت 8.

🧬 تعديل الخصائص والوراثة (Inheritance)

مثال 6: دالة تغير قيمة خاصية (عيد ميلاد)

class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def celebrate_birthday(self):
        self.age += 1
        print(f"Happy birthday! You are now {self.age}")

p1 = Person("Linus", 25)
p1.celebrate_birthday()
p1.celebrate_birthday()
_ Terminal Output
Happy birthday! You are now 26
Happy birthday! You are now 27
💡 الشرح سطر بسطر:
• الـ __init__ بياخد الاسم والسن ويخزنهم.
• self.age += 1 هنا بنزود السن بـ 1 (يعني 25 تبقى 26).
• print(f"Happy birthday! You are now {self.age}") بنطبع رسالة فيها السن الجديد.
• استدعينا الدالة مرتين، فكل مرة السن زاد.

الوراثة (Inheritance)

يعني إيه؟ لو عندك Class اسمه Person (فيه الاسم والطباعة)، وعايز تعمل Class جديد اسمه Student (طالب)، الطالب ده برضه شخص، فممكن يرث كل خصائصه، ويضيف عليه حاجة جديدة (زي سنة التخرج).

مثال 7: وراثة بسيطة

class Person:
    def __init__(self, fname, lname):
        self.firstname = fname
        self.lastname = lname

    def printname(self):
        print(self.firstname, self.lastname)

class Student(Person):
    def __init__(self, fname, lname, year):
        super().__init__(fname, lname)
        self.graduationyear = year

x = Student("Mike", "Olsen", 2019)
x.printname()
print(x.graduationyear)
_ Terminal Output
Mike Olsen
2019
💡 الشرح سطر بسطر:
• class Student(Person): هنا بنقول إن Student ده هيورث كلViewController من Person.
• super().__init__(fname, lname) ده أمر مهم جداً، بيقول للكلاس الجديد "روح نادي على الـ init بتاع الأب (Person) عشان ياخد الاسم الأول والأخير".
• self.graduationyear = year وبعد كده بنضيف حاجة جديدة خاصة بالطالب.
• x = Student(...) عملنا كائن طالب.
• x.printname() هنا استخدمنا دالة الأب (لأنه ورثها).

🌳 الوراثة (تابع) وأنواعها

مثال 8: إضافة Method جديدة في الفئة الوريثة

class Person:
    def __init__(self, fname, lname):
        self.firstname = fname
        self.lastname = lname

    def printname(self):
        print(self.firstname, self.lastname)

class Student(Person):
    def __init__(self, fname, lname, year):
        super().__init__(fname, lname)
        self.graduationyear = year

    def welcome(self):
        print("Welcome", self.firstname, self.lastname, "to the class of", self.graduationyear)

x = Student("Mike", "Olsen", 2024)
x.welcome()
_ Terminal Output
Welcome Mike Olsen to the class of 2024
💡 الشرح سطر بسطر:
• هنا ضفنا دالة welcome جوه الكلاس Student بس.
• الدالة دي بتستخدم بيانات الأب (firstname, lastname) وبيانات الطالب نفسه (graduationyear).
• عشان كده لما استدعيناها طبعت كل حاجة مع بعض.

أنواع الوراثة (Types of Inheritance)

النوع الشرح
Single كلاس واحد يورث من كلاس واحد (زي Student من Person).
Multilevel سلسلة (Class A يورث Class B، وClass B يورث Class C).
Hierarchical كلاس أب واحد، بيورث منه أكتر من كلاس (زي Person يورث منه Student و Doctor).
Multiple كلاس واحد بيورث من أكتر من كلاس أب.
Hybrid خليط بين أكتر من نوع من الأنواع اللي فوق.

🔒 التغليف (Encapsulation)

يعني إيه تغليف؟ هو إننا نخبي البيانات (الخصائص) جوه الكلاس، ومحدش يقدر يوصلها من بره غير من خلال دوال معينة (Getters و Setters). بنعمل ده عشان نحمي البيانات من التعديل الغلط.

مثال 9: Private Property (خاصية خاصة)

class Person:
    def __init__(self, name, age):
        self.name = name
        self.__age = age # Private property

p1 = Person("Emil", 25)
print(p1.name)
print(p1.__age) # This will cause an error
_ Terminal Output
Emil
AttributeError: 'Person' object has no attribute '__age'
💡 الشرح سطر بسطر:
• self.__age = age الشرطتين (_) قبل الاسم بيخلوا المتغير "خاص"، يعني مينفعش نوصله من بره الكلاس.
• print(p1.name) عادي لأن name مش خاص.
• print(p1.__age) هنا بايثون هتعمل Error لأننا بنحاول نخترق الخصوصية.

مثال 10: Getters و Setters

class Person:
    def __init__(self, name, age):
        self.name = name
        self.__age = age

    def get_age(self):
        return self.__age

    def set_age(self, age):
        if age > 0:
            self.__age = age
        else:
            print("Age must be positive")

p1 = Person("Ali", 25)
print(p1.get_age()) # 25
p1.set_age(26)
print(p1.get_age()) # 26
_ Terminal Output
25
26
💡 الشرح سطر بسطر:
• def get_age(self): دي دالة وظيفتها ترجعلك قيمة السن (بتحل مشكلة الوصول المباشر).
• def set_age(self, age): دي دالة بتغير السن، بس بشرط (لو السن أكبر من صفر).
• كده لو حد حاول يحط سن سالب، البرنامج هيرفض ويطبع رسالة تنبيه، وده بيحمي البيانات.

🎭 تعدد الأشكال (Polymorphism)

يعني إيه تعدد أشكال؟ إن يكون عندنا كلاسات مختلفة (عربية، مركب، طيارة)، وكلهم ليهم نفس اسم الدالة (move)، بس كل كلاس بينفذها بطريقته. لما نستدعي الدالة، كل كائن هيتصرف بطريقته.

مثال 11: تعدد الأشكال في الدوال

class Car:
    def move(self):
        print("Drive!")

class Boat:
    def move(self):
        print("Sail!")

class Plane:
    def move(self):
        print("Fly!")

car1 = Car()
boat1 = Boat()
plane1 = Plane()

for x in (car1, boat1, plane1):
    x.move()
_ Terminal Output
Drive!
Sail!
Fly!
💡 الشرح سطر بسطر:
• عملنا 3 كلاسات (Car, Boat, Plane) وكلهم فيهم دالة اسمها move.
• لما لفينا عليهم بـ for x in (...)، كل كائن نفذ الدالة بتاعته.
• العربية قالت Drive، المركب قالت Sail، والطيارة قالت Fly. نفس الدالة بس سلوك مختلف.
🧩 التجريد (Abstraction)

يعني إيه تجريد؟ إننا نخفي التفاصيل المعقدة، ونظهر للمستخدم واجهة بسيطة. في بايثون، بنستخدم مكتبة abc عشان نعمل كلاس مجرد (Abstract Class) مش ينفع نعمل منه كائن مباشرة، ولازم الكلاسات اللي هتورث منه تنفذ الدوال بتاعته.

مثال 12: التجريد في بايثون

from abc import ABC, abstractmethod

class Animal(ABC):
    @abstractmethod
    def doAction(self):
        pass

class Human(Animal):
    def doAction(self):
        print("I can walk and run")

class Snake(Animal):
    def doAction(self):
        print("I can crawl")

R = Human()
R.doAction()
K = Snake()
K.doAction()
_ Terminal Output
I can walk and run
I can crawl
💡 الشرح سطر بسطر:
• from abc import ABC, abstractmethod بنستورد الأدوات اللي هتخلينا نعمل الكلاس المجرد.
• class Animal(ABC): ده كلاس مجرد، مش ينفع نعمل منه كائن.
• @abstractmethod ده بيفرض على أي كلاس هيورث من Animal إنه لازم ينفذ دالة doAction.
• R = Human() هنا عملنا كائن من Human (لأنه نفذ الدالة المطلوبة).
• لما استدعي R.doAction()، اتنفذت وطبعت الجملة بتاعته.
