📝 القوائم (Lists)

يعني إيه List؟ هي طريقة لتخزين عدة قيم في متغير واحد. تتميز إنها مرتبة، قابلة للتعديل، وتسمح بالتكرار. بتتكتب بين أقواس مربعة [] وبنفصل بين العناصر بفاصلة.

fruits = ["apple", "banana", "cherry"]
print(fruits)
>_ Terminal Output
['apple', 'banana', 'cherry']
💡 الشرح بالعامية: إحنا هنا عملنا متغير اسمه fruits (فواكه)، وحطينا جواه 3 عناصر بين قوسين مربعين [] ومفصولين بفواصل. ولما طبعناه بـ print، ظهرت القائمة زي ما هي.

1. الوصول لعنصر (Indexing)

print(fruits[0]) # Output: apple
print(fruits[1]) # Output: banana
💡 الشرح بالعامية: عشان نجيب عنصر معين، بنكتب اسم القائمة وبعدين بين قوسين مربعين رقم العنصر (الفهرس). وخد بالك، بايثون بتبدأ العد من صفر، يعني أول عنصر (apple) رقمه 0، وتاني عنصر (banana) رقمه 1.

2. تغيير عنصر (Modify)

fruits[1] = "blueberry"
print(fruits)
>_ Terminal Output
['apple', 'blueberry', 'cherry']
💡 الشرح بالعامية: بما إن القائمة بتتعدل، رحنا للعنصر رقم 1 (اللي هو كان banana) وقلناله "خلي قيمتك بقي blueberry"، ولما طبعنا تاني، لقينا banana اختفت واتحولت لـ blueberry.

3. إضافة وحذف عناصر

fruits.append("orange")
print(fruits)

fruits.remove("blueberry")
print(fruits)
>_ Terminal Output
['apple', 'blueberry', 'cherry', 'orange']
['apple', 'cherry', 'orange']
💡 الشرح بالعامية: استخدمنا أمر append() عشان نزود تفاحة (orange) في آخر القائمة، وبعدين أمر remove() عشان نمسح الـ blueberry من القائمة.

📦 الصفوف (Tuples)

يعني إيه Tuple؟ هي تشبه القائمة (List) في إنها مرتبة، بس الفرق الجوهري إنها غير قابلة للتعديل (Immutable)، يعني أول ما تنشئها مينفعش تغير عناصرها تاني. بتتكتب بين أقواس عادية ().

colors = ("red", "green", "blue")
print(colors[1]) # Output: green

# colors[1] = "yellow" # This will cause an error
💡 الشرح بالعامية: هنا عملنا Tuple للألوان. نقدر نوصل لعنصر زي الـ List بالضبط بـ colors[1]، بس لو حاولنا نغير عنصر (زي الكومنت اللي تحت) هيطلع لنا Error (خطأ) لأن الـ Tuple مبيدخلش فيه تعديل بعد الإنشاء.

✍️ تمارين على القوائم والصفوف

تمرين 1: قائمة الأطعمة المفضلة

favorite_foods = ["pizza", "sushi", "ice cream"]
for food in favorite_foods:
    print(food)
>_ Terminal Output
pizza
sushi
ice cream
💡 الشرح بالعامية: عملنا قائمة بالأكل المفضل. وعشان نطبع كل أكلة في سطر، استخدمنا حلقة التكرار for. الحلقة دي بتاخد كل عنصر وتسميه food وتطبعه، وتلف لحد ما تخلص القائمة.

تمرين 2: الأرقام الأكبر من 10

numbers = [5, 12, 7, 18, 3, 20]
for number in numbers:
    if number > 10:
        print(number)
>_ Terminal Output
12
18
20
💡 الشرح بالعامية: عندنا لستة أرقام، عملنا حلقة عشان تعدي على كل رقم. جوه الحلقة، حطينا شرط if (لو) الرقم ده أكبر من 10، اطبعه. الأرقام اللي أصغر من 10 مش هتتطبع.

تمرين 3: صف المدن (Tuple)

cities = ("New York", "Paris", "Tokyo")
print(cities[1]) # Output: Paris
💡 الشرح بالعامية: عملنا Tuple فيه 3 مدن. عشان نطبع المدينة التانية، استخدمنا الفهرس رقم 1 (لأن العد بيبدأ من 0)، فطبع لنا Paris.

🎲 المجموعات (Sets)

يعني إيه Set؟ هي مجموعة غير مرتبة، غير مهرسة، وغير قابلة للتعديل (بس ممكن تضيف أو تحذف منها). الميزة الأهم إنها مابتسمحش بالتكرار، وبتتكتب بين أقواس مجعدة {}.

thisset = {"apple", "banana", "cherry", "apple"}
print(thisset)
>_ Terminal Output
{'cherry', 'banana', 'apple'}
💡 الشرح بالعامية: لاحظ إني كتبت "apple" مرتين في الإنشاء، بس لما طبعها طلعت مرة واحدة. لأن الـ Set بيمسح أي عنصر متكرر أوتوماتيك، وكمان الترتيب بيطلع عشوائي كل مرة بتشغل الكود.

1. المرور على الـ Set (Loop)

thisset = {"apple", "banana", "cherry"}
for x in thisset:
    print(x)
>_ Terminal Output
banana
cherry
apple
💡 الشرح بالعامية: عشان نلف على العناصر جوه الـ Set، استخدمنا حلقة for عادية. بس خد بالك، الترتيب اللي هيطلع مش مضمون (ممكن يطلع banana الأول أو apple).

2. إضافة وحذف عنصر

thisset = {"apple", "banana", "cherry"}
thisset.add("orange")
print(thisset)

thisset.remove("banana")
print(thisset)
>_ Terminal Output
{'banana', 'orange', 'apple', 'cherry'}
{'apple', 'cherry', 'orange'}
💡 الشرح بالعامية: استخدمنا add() عشان نضيف orange، وبعدين remove() عشان نحذف banana. زي ما قلتلك، الترتيب في الطباعة هيكون عشوائي.

📚 القواميس (Dictionaries)

يعني إيه Dictionary؟ هو هيكل بيانات بيخزن المعلومات على شكل مفتاح وقيمة (Key: Value). زي دفتر التليفونات كده، الاسم هو المفتاح والرقم هو القيمة. بيتكتب بين أقواس مجعدة {}.

person = {
    "name": "Alice",
    "age": 30,
    "city": "New York"
}

print(person["name"]) # Output: Alice
print(person["age"]) # Output: 30
💡 الشرح بالعامية: هنا عملنا قاموس لشخص. المفاتيح هي (الاسم، السن، المدينة). عشان نجيب الاسم، بنكتب اسم القاموس وبعدين بين قوسين مربعين المفتاح اللي عايزينه (زي person["name"]) وهيرجعلك القيمة اللي هي Alice.

1. المرور على القاموس (Loop)

for key in person:
    print(f"{key}: {person[key]}")
>_ Terminal Output
name: Alice
age: 30
city: New York
💡 الشرح بالعامية: هنا عملنا لوب عشان نطبع كل حاجة. الـ key هتمسك المفتاح (زي name)، وبعدين نطبعها مع القيمة بتاعتها person[key].

✍️ تمارين على القواميس

تمرين 1: قاموس الأشخاص

people = {
    "Alice": 30,
    "Bob": 25,
    "Charlie": 35
}

for name in people:
    print(f"{name} is {people[name]} years old.")
>_ Terminal Output
Alice is 30 years old.
Bob is 25 years old.
Charlie is 35 years old.
💡 الشرح بالعامية: عملنا قاموس فيه 3 أشخاص وأعمارهم. الـ Loop هتلف على الأسماء (name) وتطبع جملة فيها الاسم وسنه باستخدام الـ f-string (اللي بيدخل المتغير جوه النص بالـ {}).

تمرين 2: إضافة عنصر

people["David"] = 40
print(people)
>_ Terminal Output
{'Alice': 30, 'Bob': 25, 'Charlie': 35, 'David': 40}
💡 الشرح بالعامية: عشان نضيف شخص جديد، كتبنا اسم القاموس وبعدين قوسين مربعين فيهم المفتاح الجديد (David) وعملنا يساوي (=) وحطينا القيمة (40). بايثون هتفهم أوتوماتيك إنك عايز تضيف عنصر جديد.

تمرين 3: حذف عنصر

del people["Bob"]
print(people)
>_ Terminal Output
{'Alice': 30, 'Charlie': 35, 'David': 40}
💡 الشرح بالعامية: استخدمنا الكلمة المحجوزة del (اختصار delete) وبعدها اسم القاموس والمفتاح اللي عايزين نمسحه (Bob).

⚙️ الدوال (Functions)

يعني إيه Function؟ هي طريقة لتجميع كود معين في مجموعة واحدة عشان تقدر تستخدمه (تستدعيه) في أي وقت من غير ما تعيد كتابته. زي الماكينة كده، بتديها الحاجة الخام وهي بتطلعلك الحاجة الجاهزة.

1. دالة بسيطة بدون معاملات

def say_hello():
    print("Hello!")

say_hello() # Output: Hello!
💡 الشرح بالعامية: عشان نعمل دالة، بنكتب def (اختصار define)، وبعدها اسم الدالة say_hello، وبعدين قوسين. اللي جوه الدالة (المسافة البادئة) هو الكود اللي هيتنفذ. لما نكتب say_hello() بره، كده إحنا "استدعيناها" وخليناها تشتغل.

2. دالة بمعاملات (Parameters)

def greet(name):
    print(f"Hello, {name}!")

greet("Alice") # Output: Hello, Alice!
greet("Bob") # Output: Hello, Bob!
💡 الشرح بالعامية: هنا الدالة بتاخد "معامل" اسمه name. لما تستدعي الدالة وتديها اسم (زي Alice)، هي هتحط الاسم ده مكان المتغير وتطبع الترحيب.

3. دالة بترجع قيمة (Return)

def add(a, b):
    return a + b

result = add(3, 5)
print(result) # Output: 8
💡 الشرح بالعامية: هنا بقى الدالة بتعمل عملية حسابية، وبدل ما تطبع النتيجة، هي بترجعها (return) للمكان اللي استدعاها فيه. فحطيناها في متغير اسمه result وطبعنا المتغير ده.

✍️ تمارين على الدوال

تمرين 1: دالة المربع (Square)

def square(number):
    return number * number

print(square(4)) # Output: 16
print(square(7)) # Output: 49
💡 الشرح بالعامية: دالة بتاخد رقم (number) وبترجع حاصل ضربه في نفسه (عشان نطلع المربع). لما دخلنا 4، طلعت 16.

تمرين 2: دالة الضرب (Multiply)

def multiply(a, b):
    return a * b

print(multiply(3, 4)) # Output: 12
print(multiply(7, 2)) # Output: 14
💡 الشرح بالعامية: دالة بتاخد معاملين (a و b)، وبترجع حاصل ضربهم.

تمرين 3: دالة الزوجي والفردي (is_even)

def is_even(number):
    return number % 2 == 0

print(is_even(4)) # Output: True
print(is_even(7)) # Output: False
💡 الشرح بالعامية: عشان نعرف الرقم زوجي ولا فردي، بنقسمه على 2 ونشوف باقي القسمة (%). لو الباقي صفر (== 0) يبقى زوجي (True)، غير كده فردي (False).

⚖️ جدول مقارنة (Lists vs Tuples vs Sets vs Dictionaries)

الجدول ده هيفرق معاك جداً في الامتحان عشان تفتكر خصائص كل نوع:

الخاصية List (قائمة) Tuple (صف) Set (مجموعة) Dictionary (قاموس) Function (دالة)
الأقواس المستخدمة [ ] ( ) { } { "key": "value" } def function_name():
الترتيب (Ordered) مرتبة مرتبة غير مرتبة مرتبة لا ينطبق
التعديل (Mutable) قابلة للتعديل غير قابلة للتعديل غير قابلة للتعديل (لكن نضيف/نمسح) قابلة للتعديل لا ينطبق
الفهرس (Indexing) مهرسة (Index) مهرسة (Index) غير مهرسة مفتاح (Key) بدل الفهرس لا ينطبق
السماح بالتكرار تسمح بالتكرار تسمح بالتكرار لا تسمح بالتكرار المفتاح لا يتكرر (القيم تتكرر) لا ينطبق
متى تستخدمها؟ لتخزين مجموعة بيانات هتتغير (تزيد/تقل). لتخزين بيانات ثابتة مش هتتغير (زي الإحداثيات). للتخلص من التكرار أو معرفة العناصر الفريدة. لربط بيانات ببعضها (زي الاسم ورقم التليفون). لتجميع كود متكرر وإعادة استخدامه بدون تكرار.
