أنواع هياكل البيانات بالتفصيل
١. المصفوفة Array
حجم ثابت، عناصر من نفس النوع، وتخزن في مواقع متتالية ويبدأ الفهرس بالصفر.
٢. الطابور Queue
يعمل بآلية FIFO (الداخل أولاً يخرج أولاً) زي طابور التذاكر وجدولة المهام.
٣. المكدس Stack
يعمل بآلية LIFO (الداخل آخراً يخرج أولاً) عبر Push و Pop، زي التراجع Undo في Word.
٤. القائمة المرتبطة

بنية هرمية غير خطية تتكون من عقد، تبدأ من عقدة رئيسية تُسمى
الجذر (Root)
ويتفرع منها عقد فرعية (Children)، وهي البنية المثالية لتنظيم أنظمة الملفات والمجلدات.

أمثلة بايثون العملية مع النتائج بالتفصيل
أمثلة الشروط و Match وحلقات While من المحاضرة
١. جملة If والمسافة البادئة (مع مقارنة حالة الخطأ):
a = 33 b = 200 if b > a: print("b is greater than a")
النتيجة بعد التشغيل:
b is greater than a
تنبيه المحاضرة: كتابة print بدون مسافة بادئة (Indentation) يسبب خطأ IndentationError مباشرة.
٢. جملة Match-Case لاختيار اليوم:
day = 4 match day: case 1: print("Monday") case 2: print("Tuesday") case 3: print("Wednesday") case 4: print("Thursday") case 5: print("Friday") case 6: print("Saturday") case 7: print("Sunday")
النتيجة بعد التشغيل:
Thursday
٣. حلقة While مع أمر الخروج Break:
i = 1 while i < 6: print(i) if (i == 3): break i += 1
النتيجة بعد التشغيل:
1 2 3

💻 المحاضرة الثانية
أمثلة بايثون العملية مع النتائج بالتفصيل
حلقات While المتقدمة وحلقات For على القوائم والنصوص
٤. جملة Continue مع حلقة While (تخطي دورة واحدة):
i = 0 while i < 6: i += 1 if i == 3: continue print(i)
النتيجة بعد التشغيل (لاحظ اختفاء الرقم 3):
1 2 4 5 6
٥. حلقة While مع جملة Else:
i = 1 while i < 6: print(i) i += 1 else: print("i is no longer less than 6")
النتيجة بعد التشغيل:
1 2 3 4 5 i is no longer less than 6
٦. حلقة For على قائمة عناصر (List):
fruits = ["apple", "banana", "cherry"] for x in fruits: print(x)
النتيجة بعد التشغيل:
apple banana cherry
٧. حلقة For للمرور على حروف النص (String):
for x in "banana": print(x)
النتيجة بعد التشغيل:
b a n a n a

💻 المحاضرة الثانية
أمثلة بايثون العملية مع النتائج بالتفصيل
تريكات Break و Continue مع القوائم ودالة range() كاملة
٨. الخروج بـ Break (الطباعة قبل Break):
fruits = ["apple", "banana", "cherry"] for x in fruits: print(x) if x == "banana": break
النتيجة بعد التشغيل:
apple banana
٩. الخروج بـ Break (Break قبل أمر الطباعة):
fruits = ["apple", "banana", "cherry"] for x in fruits: if x == "banana": break print(x)
النتيجة بعد التشغيل:
apple
١٠. استبعاد عنصر باستخدام Continue (تخطي banana):
fruits = ["apple", "banana", "cherry"] for x in fruits: if x == "banana": continue print(x)
النتيجة بعد التشغيل:
apple cherry
١١. استخدام دالة range(6) مع حلقة For:
for x in range(6): print(x)
النتيجة بعد التشغيل (تبدأ من 0 وحتى 5):
0 1 2 3 4 5
١٢. تحديد البداية والنهاية range(2, 6):
for x in range(2, 6): print(x)
النتيجة بعد التشغيل:
2 3 4 5
١٣. تحديد معدل الزيادة والخطوة range(2, 30, 3):
for x in range(2, 30, 3): print(x)
النتيجة بعد التشغيل:
2 5 8 11 14 17 20 23 26 29
١٤. مثال طباعة الأرقام مع جملة نصية من 1 إلى 10:
for i in range(1, 11): print("The number is", i)
النتيجة بعد التشغيل:
The number is 1 The number is 2 ... The number is 10
